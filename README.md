# אפליקציית גלריה והקרנה - תנובה (פורום 100 – מודל מנהיגות)

אפליקציה מלאה לשיתוף תמונות, משפטים והתחייבויות לפעולה לאירוע פורום 100 – מודל מנהיגות תנובה.

## עמודי האפליקציה

1. **עמוד משתמש (`/`)**:
   - בחירת קבוצה (1-20).
   - הזנת משפט (עד 80 תווים).
   - הזנת **״התחייבות לפעולה״**.
   - העלאת תמונה/וידאו עם מד התקדמות אחוזי בזמן אמת.
   - אישור קבלה ואפשרות ביטול/מחיקה עצמית של התמונה שנשלחה.

2. **עמוד הקרנה וצפייה בלייב (`/stream`)**:
   - פאנל ניהול הקרנה בתלת-ממד (3D Hub).
   - בחירת זרם: ״כל הקבוצות״ (גלובלי) או קבוצה ספציפית 1-20.
   - בקרת מהירות מעבר בין שקופיות (1 עד 20 שניות).
   - מצגת אוטומטית במסך מלא עם אפקטי מעבר חלקים.
   - שכבת טקסט צפה עם המשפט וההתחייבות לפעולה של הקבוצה.
   - סנכרון חי ועדכון אוטומטי בלייב כל 3 שניות.

3. **עמוד ניהול אדמין (`/admin`)**:
   - כניסה מאובטחת באמצעות סיסמה (ברירת מחדל: `tnuva2025`).
   - העלאה מרוכזת של מספר קבצים בבת אחת.
   - מצב סידור מחדש מתקדם: גרירה ושחרור (Drag & Drop), הזזה למעלה/למטה, קפיצה להתחלה/לסוף והזנת מיקום מספרי מדויק.
   - מחיקה מרוכזת לפי קבוצה או מחיקת מספר תמונות נבחרות (צ'קבוקסים).
   - מחיקה בודדת של תמונות ושמירת סדר מותאם אישית לשרת.

## הרצה מקומית

```bash
# התקנת תלויות
npm install

# הרצת שרת פיתוח
npm run dev
```

האפליקציה תרוץ בכתובת: `http://localhost:3000`

## פריסה ל-Vercel

ניתן לפרוס בלחיצה אחת ל-Vercel או באמצעות Vercel CLI:
```bash
vercel
```
